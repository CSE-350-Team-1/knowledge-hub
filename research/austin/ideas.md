Design Principles
-Listing functionality FIRST
-Adaptive to user data
-Use cloud storage as much as safety allows
-Abstractions of sensitive data
-Idiot proof design

Functional Requirements
-Mandatory user logins
-Grocery list display
-Grocery list item add/delete
-Multi-list system
-List item (in tabs)

Non-Functional Requirements
-Smart list fill
-Speech to text
  -Organizes speech into list
-Agentic assistant
  -Reminds you to get key ingredients for recipes you want to make
-List price
-Item price
-Webscraping for prices
-Custom list items
-List sharing
