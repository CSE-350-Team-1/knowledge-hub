# Suggested name

CleverShop - subject to domain availability.

# Main idea

I believe that it would be a great idea for the team to work on a **grocery planning service**. Such an undertaking would be manageable in scope at a most basic level and allow us to introduce more advanced features if necessary. As for the project's larger meaning, it would speak to regular individuals' economic welfare, namely by providing a centralized service to make managing grocery trips easier.

# Characteristic features

## Smart shopping lists
    - The user sets up shopping lists manually or following a set repeating schedule.
    - The user selects the desired items.
    - The user marks down the purchased items.
    - An algorithm is used to help autofill subsequent shopping trips.
    - An algorithm is used to reorganize shopping items according to past user activity (makes selection easier).

## Persistent notifications
    - The user is notified when a planned grocery trip is to begin shortly.
    - The user is reminded to mark down purchased items (as opposed to non-purchased items) during the shopping trip.
    - The user is reminded to record the price of the shopping trip.

## Shopping analytics
    - The user is presented with figures relating to shopping items and expenses.
