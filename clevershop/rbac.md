# CleverShop role-based access control

To ensure a secure experience for all users, strict RBAC is to be applied at all levels of Clevershop software.

## Roles and permissions
- **User** (default)
  - Modify own account
  - Manipulate own lists

- **Manager**
  - Modify own account
  - Manipulate all user account lists
  - Add user accounts
  - Delete user accounts

- **Admin**
  - Modify own account
  - Manipulate all user account lists
  - Add user accounts
  - Delete user accounts
  - Add manager accounts
  - Delete manager accounts
