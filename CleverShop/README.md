# CleverShop

CleverShop is a web application that aids in the digital organization of shopping items. Instead of relying on paper or clunky note-taking apps, the user is invited to spend minimal time setting up their lists and logging their purchases. The vast majority of data is stored server side, allowing for increased convenience and safe record-keeping.

## Design principles
To aid in project development, guidelines are put in place to determine the technical approach to be adopted. These principles apply to all development situations.

- Listing functionality first
    * The ability to create and fill shopping lists is to be treated as the program's characteristic feature. Whenever a design or development choice is to be made, this is the absolute priority.

- Adaptive functionality
    * User data is for more than just record keeping. Whenever practical, it should be taken advantage of to implement smart features and improve seamlessness within the application.

- Idiot-proof design
    * The user is to be presented with an application that requires minimal technical expertise. Functionality should be easy to understand and use at a glance.

- Cloud storage first
    * A remote server is to be the primary method of storage for user data. Exceptions can be made if sensitive information is at risk.

- Abstraction of sensitive data
    * Sensitive organization information is to be kept away from the user. This is to be ensured with thoughtful architectural planning.
